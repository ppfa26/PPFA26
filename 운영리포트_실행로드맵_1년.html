모두의사업친구 사업 운영 리포트
롤모델 유닛이코노믹스 + 1년 실행 로드맵

고이·삼쩜삼·아정당의 수익구조를 벤치마크로, 사업자 DB 확보 → 1회성 결제 → 전문가 연결 → 1:1 자문으로 매출을 키우는 30·90·180·360일 실행 계획. 책상 옆에 붙여두고 매주 체크하세요.

작성: 모두의사업친구(신주엽 대표) · 기준 2026년 · 매출 수치는 목표(가정)이며 실제 시장 반응에 따라 조정
전략 한 장

우리가 벌 돈은 "29,900원"이 아니라 "DB"에서 나온다

소액 단건 결제만으로는 매출이 안 터진다. 세 롤모델의 공통 공식 = 무료/저가 유입 → 가치 확정 시 과금 → DB 위에 고단가 상품 얹기.

① 캐시카우 (~2026년)

1억↑ 기보/신보 대행·컨설팅으로 현금 유지. 단, 내년 법 개정 시 대행 금지 예정 → 여기 더 투자 금지, 유지선까지만.

② 씨앗 (지금부터)

매칭 SaaS 1회성 결제(29,900원)로 사업자 DB 최대 확보. 결제는 손익분기·DB 정제 용도.

③ 폭발 엔진 (대행 종료 후)

확보한 DB로 세무·노무·관세사 연결 수수료 + 대표님 직접 1:1 자문·원데이 세미나(고단가).

가장 큰 리스크 — 대행은 시한부다 내년 대행 금지 시 현재 매출의 큰 축이 사라진다. 대행 수요를 "그럼 어떻게 직접 하나요?" = 교육·자문 수요로 전환시키는 계단을 지금 미리 깔아야 절벽이 아니라 연결이 된다.
REVENUE STAIRCASE

01. 매출 계단 — 한 명의 고객을 위로 올린다

DB에 들어온 한 명을 아래 계단으로 계속 올리는 게 이 사업의 전부입니다.

무료 진단 0원 · DB 확보
AI 매칭 리포트 + 신청방법 교육 29,900원 · 1회성
전문가 연결 (세무 → 노무·관세 순차) 건당 수수료
1:1 자문 / 원데이·줌 세미나 (대표님 직접) 회당 고단가
1억↑ 기보/신보 컨설팅 ~2026 성공보수
핵심 — 올라갈수록 객단가가 폭증한다 29,900원짜리 고객 100명보다, 그중 1:1 자문(회당 수십만원)으로 올라온 5명이 매출을 만든다. 리포트는 미끼, 자문이 본체.

PARTNER · ADVISORY

03. 전문가 연결 & 자문 — 지금 결정된 사실

✅ 세무 파트너 — 확보됨

가장 먼저 "세무사 연결" 기능부터 오픈. 수요·전환율·수수료 구조를 세무로 먼저 검증한 뒤 노무·관세로 확장.

⬜ 노무·관세 — 미확보

아직 파트너 없음 → 기능부터 만들지 말 것. 파트너 확보 후 오픈(껍데기 기능은 신뢰를 깎음).

🎤 1:1 자문·세미나 — 대표님 직접

직업군인·경영컨설턴트 출신, 승인 100건·100억 이력이 그 자체로 상품. "신주엽 대표에게 직접 배우는 정부지원사업"으로 브랜딩.

⚖️ 개인정보 제3자 제공 동의

대표님 결정대로 가입 단계에서 미리 동의 확보(하든 안 하든 나중에 편함). 30일 내 약관·동의 UI 정비.

주의 — 대표님이 병목이 될 수 있음 자문·세미나를 대표님이 직접 하면 시간이 곧 매출 상한. 그래서 ①회당 단가를 충분히 높이고 ②1:多 세미나(줌/원데이)로 시간당 매출을 키우고 ③반복 콘텐츠(녹화 강의)로 나중에 레버리지.
PHASE 1

04. 월단위 1년 실행 로드맵

각 단계는 앞 단계 위에 쌓입니다. 매주 금요일 체크박스로 진척 확인하세요.

D+30일 · 기반 다지기목표매출 유지: 대행/컨설팅 현금 + 베타 DB 확보
신규 DB 300~500명
무료진단 완료율 측정 시작
SaaS 매출 0원(베타)
대행 파이프 유지

해야 할 일

  • 개인정보 제3자 제공 동의 약관·가입 UI 정비 (세무사 연결 대비, 최우선)
  • 진단 리포트에 "예상 수혜 지원금 규모" 숫자 노출 (과금 명분 · 로직 불변)
  • 업종별 유입 콘텐츠 4~5개 발행 (블로그/인스타 — "인천 소상공인 지원사업 총정리" 등)
  • 토스 심사 진행상황 점검 → 통과 시 즉시 29,900원 결제 오픈 준비
  • 대행 파이프라인은 유지선까지만 (신규 확장 X, 기존 승인건 마무리)
D+90일 · 유료 전환 시작목표매출: SaaS 결제 개시 + 세무 연결 첫 매출
누적 DB 1,500~2,000명
리포트 결제 월 50~100건
SaaS 매출 월 150~300만
세무 연결 첫 성사

해야 할 일

  • 29,900원 결제 정식 오픈 (토스 통과 후) → 베타 유입의 유료 전환율 측정
  • 세무사 연결 기능 오픈 — 수수료 구조/전환율 검증(계단 3단계 첫 가동)
  • 콘텐츠 누적 15개+, 유튜브/릴스 1채널 시작 (아정당식 저비용 유입)
  • 무료 "맞춤 신규공고 알림 구독" 도입 → 미결제 방문자 lock-in(고이식)
  • 1:1 자문 파일럿 3~5건 테스트(지인·기존 고객) → 적정 단가 탐색
D+180일 · 고단가 상품 장착목표매출: 자문/세미나 정식 상품화
누적 DB 4,000~6,000명
리포트 월 150~250건
SaaS+연결 월 500~800만
자문·세미나 월 300만+

해야 할 일

  • 원데이/줌 세미나 정식 오픈 — 대표님 직접, 1:多로 시간당 매출 극대화
  • 1:1 자문 정식 상품화(회당 단가 확정) — 리포트→연결→자문 계단 완성
  • 세무 연결 데이터 좋으면 노무·관세 파트너 확보 착수
  • 세미나 녹화강의 1개 제작 → 반복 판매(대표님 시간 레버리지)
  • 대행 종료 대비: 기존 대행 고객에게 "직접 신청 교육"으로 전환 제안
D+360일 · SaaS가 메인, 대행 졸업목표매출: 월 1,500만+ / DB 1만+
누적 DB 10,000명+
리포트 월 300건+
연결+자문 월 1,000만+
총매출 월 1,500만+

해야 할 일

  • 매칭 SaaS를 메인 매출원으로 전환 — 대행 의존도 최소화(법 개정 대응 완료)
  • 노무·관세 연결 정식 가동 → DB당 복수 수익원(아정당식 반복판매)
  • 세미나 정기 개최(월 1~2회) + 녹화강의 상시 판매
  • "초기창업자·정부지원 초보 사장" 타깃 브랜딩 확립 → 안내·추천·매칭 대표 플랫폼 포지셔닝
  • 단위경제 점검: 고객 1명당 LTV(리포트+연결+자문) vs CAC → 광고 확대 판단

DON'T

06. 지금 하지 말아야 할 것 (에너지 낭비 방지)

  • ❌ 대행 사업 신규 확장 — 내년 법 개정으로 사라질 매출에 인력·시간 추가 투입 금지(유지선까지만).
  • ❌ 노무·관세 연결 기능 선제작 — 파트너 없이 껍데기 기능은 신뢰만 깎음. 세무로 먼저 검증.
  • ❌ 매칭 로직 수정 — 핵심 자산. 결과 "표기"만 개선하고 로직은 절대 손대지 않음.
  • ❌ 검증 안 된 가격 실험 — 29,900원 유지, 90일 데이터 확인 후 조정.
  • ❌ 결제 시스템 선구축 — 토스 심사 통과 후 오픈.
