💰 지금 매출

컨설팅 + 대행 수수료 → 월 3,000만. 단, 내년 대행 축소 리스크.

PRICE · 1:1 자문

03. 1:1 자문 — 얼마 받나

근거: 승인 100여 건·지원금 100억+ 이력 = 이미 "검증된 전문가". 싸게 받으면 싸구려 인식 + 시간 손해.

🟢 시작가 (검증기)

20만원 / 60분

기존 상담 고객부터. "제대로 짚어준다"는 후기 쌓기용.

🔵 정착가 (표준)

30만원 / 60분

후기·전환 확인되면 인상. 대표님 경력엔 적정선.

🟡 프리미엄 (심화)

50만원 / 90분+서류검토

사업계획서·서류 실제 첨삭까지. 고액 지원사업 준비 고객.

운영 팁 ① 패키지로 묶어라: "단발 30만" vs "3회 75만(회당 25만)" → 3회권이 이득처럼 보이게. ②무료진단 → 유료자문 자연 연결: 진단은 미끼, 자문이 상품. ③처음엔 주 3~5건 한정으로 "예약 마감" 희소성 연출.

04. 세미나 — 얼마 받고, 어디까지 가르치나

가격 (형태별)

형태시간1인 가격정원회당 매출(예)
줌 라이브 (입문)2시간3만~5만20~50명60만~250만
원데이 오프라인3~4시간5만~10만10~20명50만~200만
녹화강의(VOD) ★-3만~9.9만무제한한번 만들고 무한판매
핵심 전략 (고이·삼쩜삼 방식) ① 줌 3만원(저가)으로 사람 모아라 → 진입장벽 낮춰 DB 대량 확보 → 여기서 1:1 자문·컨설팅으로 업셀. ② 원데이 1회를 녹화해서 VOD로 → 시간 안 들이고 계속 팔리는 자산(대표님 몸값 = 시간인데, VOD는 시간 복제).

어디까지 가르치나 (범위 = 이게 제일 중요)

✅ 가르쳐라 (미끼·신뢰)

  • 정부지원사업 종류·일정·자격 큰 그림
  • 내 업종에 맞는 사업 찾는 법(진단 로직 개념)
  • 사업계획서 기본 뼈대·흔한 탈락 사유
  • 서류 준비 체크리스트·용어 정리

🔒 남겨둬라 (유료의 이유)

  • 내 사업에 딱 맞는 사업 매칭·전략 → 1:1 자문
  • 사업계획서 실제 첨삭·대필 수준 → 컨설팅·대행
  • 심사위원 관점 디테일 코칭 → 프리미엄 자문
  • 승인까지 실무 대행 → 본업(수수료)
절대 원칙 세미나에서 "방법"은 다 알려주되, "내 케이스 적용"은 유료로 남겨라. 다 가르치면 고객이 자문·컨설팅 살 이유가 사라짐. 세미나=신뢰 쌓기+DB 확보용 미끼, 돈은 1:1과 대행에서.
